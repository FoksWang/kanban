# Roadmap

## Portfolio release

- [x] React 19, TypeScript, Vite, and route setup.
- [x] Tailwind v4 and shadcn/ui theme and primitives.
- [x] Reusable Board, KanbanGroup, and Task components.
- [x] Group and task creation.
- [x] Task deletion with confirmation.
- [x] Pointer and keyboard drag and drop, including empty groups.
- [x] LocalStorage persistence of groups, tasks, moves, and deletions.
- [x] ESLint, Prettier, state tests, and production-browser tests.
- [x] GitHub Actions checks and GitHub Pages deployment workflow.
- [x] English README and architecture documentation.
- [ ] Add a short recorded walkthrough.

## Optional future work

- Task editing, labels, descriptions, and undo.
- Additional browser/mobile accessibility coverage.
- Explicit storage-error feedback and import/export backups.
- Authentication, backend persistence, and collaboration if this becomes a team product.
